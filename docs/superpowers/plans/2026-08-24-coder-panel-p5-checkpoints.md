# Coder Panel P5 — Checkpoints (shadow-commit snapshots + diff review + revert) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Give the coder panel whole-workspace **checkpoints** — a pre-turn and post-turn Git shadow-commit snapshot for every coder turn, stored as refs outside `refs/heads` and never touching the user's HEAD/branches/index/worktree; plus **human-only** per-turn diff review and revert. Revert restores the working tree to a turn's **PRE-checkpoint** (undoing that turn and every later turn), after auto-saving a safety checkpoint. The agent gets NO checkpoint/revert tool.

**Locked product decision (Omar, 2026-08-24):** Revert = "undo this turn + all after" → restore to the turn's PRE snapshot; a safety checkpoint of the current tree is captured first; turn history stays visible (only the working tree changes).

**Architecture (decided defaults — engineering-correct where the spec was silent/ambiguous):**
- **Shadow commits** via a throwaway `GIT_INDEX_FILE`: `read-tree` (empty) → `add -A` → `write-tree` → `commit-tree` → `update-ref`. Never runs plain `git add`/`commit` (those mutate the real index/HEAD). Repo is `<user_dir>/workspace` (= the file-API root); journal, `home/`, `kimi-share/`, and `blueprint-trust.json` all sit OUTSIDE it, so `add -A` never sweeps them (and the trust store is never reverted — for free).
- **Per-checkpoint refs** (deviation from the spec's literal single-`refs/sanad/checkpoints/<cid>` wording — REQUIRED for correctness): `refs/sanad/checkpoints/<cid>/<turnId>-pre` and `-post`, plus `.../safety-<turnId>-<n>` for safety checkpoints. A single moving ref would make earlier checkpoints unreachable → GC-eligible, breaking "review/revert an earlier turn." Per-checkpoint refs keep every snapshot reachable and are pruned in lockstep with `coder_journal_turns_keep`.
- **Snapshots**: unconditional PRE at `start_turn`; POST at the `_consume` finally, **skipped when the tree equals PRE** (no-op turn). SHAs live in a `CoderRunner._checkpoints` side-map (TurnState is shared with ArchitectRunner and must not grow checkpoint fields), merged into the journal's per-turn record, and emitted as a `{kind:"checkpoint"}` journal item so followers see them live.
- **Diff**: `GET /diff?turnId&path?` → name-status + unified patch (`git diff <pre> <post>` for a finished turn; `<pre>` vs worktree for a running turn — server auto-detects by turn status), truncated by a new `coder_diff_max_bytes` (default 200_000, matching `git_ops.show`'s existing cap). Rendered as diff **text** mirroring the existing ContextDock History section — NOT the `DiffView` component (which needs before/after file content, the wrong shape).
- **Revert**: `POST /revert {turnId}` → restore worktree to `turnId`'s PRE checkpoint. Refuse with 409 while ANY conversation in the workspace is busy (`any(r.busy for r in list_conversations(root))` — no write-lease until P6). Under a **shared per-workspace lock** (extract blueprint's private `_lock_for` into a small shared module so revert and blueprint apply/rollback are mutually exclusive on `.sanad/**`). Steps: safety-checkpoint (shadow commit of the current tree) → temp `GIT_INDEX_FILE` `read-tree <pre>` → `checkout-index -a -f` → delete tracked files absent from the target tree. Human-only.
- **Blueprint coupling (no new blueprint code):** a coder revert that writes `.sanad/**` silently invalidates any pending blueprint rollback record (its post-apply sha256 hashes stop matching) — the spec's "trips the drift-refusal as designed." The UI warns about this class of change.
- **git add -A nested-repo caveat (v1 accepted limitation):** the codebase has no submodule/nested-`.git` handling; an agent that plants a nested repo (e.g. `git clone`) yields a gitlink in the shadow commit. v1 accepts + documents this; no detection built (dogfood-acceptable).

**Tech Stack:** Python 3.14 / FastAPI / asyncio (terminal-server: `uv run pytest tests/ -q`, ~17s). TypeScript / Next.js / React (sanad-web: `pnpm test` + `pnpm exec tsc --noEmit`). ### Task 1: Git shadow-checkpoint plumbing in `GitRepo` (foundation, riskiest)

**Files:** Modify `terminal-server/src/sanad_terminal/git_ops.py`; add/extend `terminal-server/tests/test_git_ops.py` (or a new `test_git_checkpoints.py`).

**Interfaces (new `GitRepo` methods — all use the existing subprocess/uid/env machinery; all operate via a throwaway `GIT_INDEX_FILE` temp file, never the real index):**
- `async def create_checkpoint(self, ref: str, message: str, *, parent: str | None = None) -> str | None`: build a tree from the CURRENT worktree via a throwaway index (`GIT_INDEX_FILE=<tmp>`: `read-tree` empty/`--empty` → `add -A` → `write-tree`), then `commit-tree <tree> [-p <parent>] -m <message>` (parent = the previous checkpoint SHA for that conversation if given, so checkpoints chain), then `update-ref refs/sanad/checkpoints/<ref>` to the new commit. **Skip-when-clean:** if `parent` is given and the new tree equals the parent commit's tree, return `None` and do NOT create a commit/ref. Returns the commit SHA (or None). Must delete the temp index file always (finally).
- `async def checkpoint_diff(self, base: str, target: str | None, *, path: str | None = None, max_bytes: int) -> dict`: `git diff --name-status <base> <target-or-worktree>` + `git diff <base> <target-or-worktree> [-- <path>]`; when `target is None`, diff base vs the working tree. Return `{"nameStatus": [{"status","path"}...], "patch": <str>, "truncated": bool, "additions": int, "deletions": int, "filesChanged": int}` (parse `--numstat` for the counts). Truncate patch at `max_bytes`. `base`/`target` validated as hex 4-64 (reuse `show()`'s ref-validation pattern).
- `async def restore_to(self, tree_ish: str) -> None`: restore the WORKTREE to `tree_ish` via a throwaway `GIT_INDEX_FILE`: `read-tree <tree_ish>` → `checkout-index -a -f --prefix=<root>/` (or run with cwd=root and no prefix) → then delete tracked files present in the worktree but absent from `tree_ish` (compute via `git diff --name-only --diff-filter=D <tree_ish> <current-worktree>` using the throwaway index, or `git ls-files` vs the tree). MUST NOT touch the user's real index or HEAD. (The caller — Task 3 — holds the workspace lock and has already taken a safety checkpoint.)
- `async def prune_checkpoints(self, cid: str, keep_turn_ids: list[str]) -> None`: delete `refs/sanad/checkpoints/<cid>/*` refs whose turnId is not in `keep_turn_ids` (align with journal retention). Use `for-each-ref` + `update-ref -d`.
- Ref-name helper: `_checkpoint_ref(cid, turn_id, kind)` → `refs/sanad/checkpoints/<cid>/<turnId>-<kind>` (kind ∈ pre|post|safety-N). Validate cid/turnId against the existing `CONVERSATION_ID_RE`/turn-id shapes so a ref name can't be injected.
